CoolerScreen

Unofficial tool for the Lovingcool SC70 USB screen Screen: not checked
The screen is on the standard serial driver, so it will turn its display off about 30 seconds after any program closes its port. Click Set up screen (one-time) to fix this permanently.
Windows couldn't connect to the screen at startup (a known quirk). Click Reconnect (needs one administrator approval).

Import

Drop a video, GIF, image or vendor theme (.ht) here, or click to choose a file

After the file is added you pick loop length, fps and quality, see the estimated size, and convert. The clip is cropped to fill 2400x1080, the notch mask is applied, then it is rotated and compressed to fit the screen.

Screen slots (Intro plays once at power-on, then Loop shows forever)

Startup and standby animations share about 10 MB on the screen. Sending a big file to one slot leaves less room for the other. Clearing a slot uploads a 1-frame black clip.

Advanced

By default "Send to screen" puts your clip in the Loop slot, makes the Intro slot black, and starts playback.

Set up switches the screen to Microsoft's WinUSB driver (no background program needed). Restore puts the standard COM-port driver back; the vendor app can then see the screen again.
